# Skinlines Art Space — website prototype

A first draft of a website for Skinlines Art Space, the tattoo studio and art space on Pink Street, Lisbon. Built by Eduardo Nogueira in October 2026 to show the studio how its site could look and feel. It is a prototype, not the studio's official website.

Photos belong to the studio and its artists (@lisbon_skinlines_studio, @olesya_tattoo, @solar_tattoo) and are used here only for this prototype.

Single static page: `index.html` plus the `img/` folder. Add `#motion` to the URL to force the animations on when the operating system asks for reduced motion.
